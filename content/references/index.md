Основной источник структуры — [снимок страницы roadmap.sh от 2026-11-23](roadmap-ai-engineer-2026-11-23.pdf), предоставленный пользователем. Это трёхстраничный PDF со снимками страницы; текст тем перенесён по изображению, а не из текстового слоя.

Ранее использованный [экспорт PDF](https://roadmap.sh/pdfs/roadmaps/ai-engineer.pdf) не содержал всех разделов снимка и больше не служит основой оглавления. [Веб-страница roadmap](https://roadmap.sh/ai-engineer) может меняться после даты снимка.

## Правила переноса

- Порядок папок следует основному пути снимка: введение → работа с LLM → промпты → контекст → модели → embeddings → RAG → агенты → MCP → безопасность → оценки и наблюдаемость → мультимодальность → инструменты разработки.
- LLM Observability, LLM Evaluations и Regression Testing объединены одной папкой с отдельными подразделами.
- Типы моделей, платформы и API объединены в AI Models. Core LLM Elements вынесен отдельно из прежней папки моделей.
- Заголовки и названия инструментов передают содержание снимка, а не подтверждают актуальность API, доступность продукта или техническую корректность его классификации. Перед конспектированием проверяй документацию.
- Отметки прохождения сохраняются по уже зафиксированным сообщениям пользователя. Перечёркивание узлов на снимке не меняет остальные статусы автоматически: снимок предоставлен для уточнения структуры.
- Углублённое прохождение раздела и выполненная практика не выводятся из знакомства с термином во введении.
- Дополнительные темы прежнего плана сохранены отдельно от пунктов снимка. Готовые конспекты не дублируются при смене структуры.

## Изменения относительно прежнего оглавления

Добавлены отдельные разделы Context Engineering, MCP и Evaluation & Observability. Расширены списки платформ, моделей, способов RAG, инструментов агентов и мультимодальных задач. Появились Prompt Anatomy, Context Layers, Memory Systems, Context Compaction, Multi-agent Context Sharing, Prompt Caching, Streaming Responses и другие пункты снимка.
